# Rinder
A one stop solution to find your next roomate, tenant, landlord with a easy going and relaxed swipe based UI built on HTML, CSS and JavaScript, integrated with a python + Fast API backend and Firebase supported database.


RINDER STATIC WEBSITE

Files:
- index.html       Home page
- privacy.html     Privacy statement
- terms.html       Terms of Use
- about.html       About page
- styles.css       Shared responsive styles
- script.js        Scroll controls + demo login modal

How to run:
1. Open index.html directly in a modern browser, or
2. Run a local server from this folder, e.g. `python -m http.server 8000`, then visit http://localhost:8000

Notes:
- The login form is a working front-end demo. Connect its submit handler in script.js to your authentication endpoint.
- Legal language is a product draft and should be reviewed by a qualified lawyer before production launch.
